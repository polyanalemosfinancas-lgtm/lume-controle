Conectar ao Firebase

Este painel precisa da configuração do seu projeto Firebase (o mesmo lume-financas usado no painel de pendências).

  1. Acesse console.firebase.google.com → projeto lume-financas
  2. Engrenagem ⚙ → Configurações do projeto → seção Seus apps
  3. Copie o bloco firebaseConfig = { ... }
  4. Abra este arquivo HTML no bloco de notas, procure por COLE_AQUI no início do script e substitua pelos seus valores
  5. Salve e suba de novo no GitHub / Vercel

Se preferir, me envie o bloco de configuração no chat do Claude que eu devolvo o arquivo pronto.
